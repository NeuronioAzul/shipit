## Plan: Atualização manual e sinalização de nova versão

Separar o fluxo de atualização em verificar → baixar → instalar, mantendo apenas a checagem automática na inicialização e removendo qualquer download/instalação sem consentimento. Centralizar o estado da atualização no processo principal, persistir o reconhecimento da notificação por versão, usar indicadores nativos por plataforma (overlay na taskbar no Windows, badge no Dock/launcher em macOS/Linux) e reaproveitar a UX, mesma fonte de estado, os mesmos textos e, quando fizer sentido, os mesmos componentes de interface entre Configurações e a nova modal do menu Help.

**Decisions**
- Incluído: checagem automática na inicialização continua ativa, mas sem download ou instalação automática.
- Incluído: escolher quando instalar significa instalação explicitamente manual; não haverá agendamento nem lembrete posterior nesta entrega.
- Incluído: equivalência cross-platform para o indicador externo será tratada por prioridade de plataforma, não pela mesma API nativa em todos os sistemas.
- Windows: usar overlay na taskbar como indicador externo principal da nova versão.
- macOS: usar badge no Dock como indicador externo principal da nova versão.
- Linux: usar badge no launcher quando houver suporte; se o ambiente não suportar badge nativo, manter como fallback obrigatório o badge interno com sonar no Header.
- Incluído: a área de Configurações deve abrir já focada na seção de atualização quando a origem for badge ou notificação.
- Restrição técnica: ações de botão em Notification do Electron são suportadas em macOS/Windows; no Linux o fallback planejado é clique para abrir a área de atualização, mantendo o botão de instalação dentro do app.

**Further Considerations**
1. Se o badge de launcher não estiver disponível em determinados ambientes Linux fora do Unity, tratar isso como fallback aceitável e manter como garantia mínima o badge interno com sonar no Header, sem bloquear a entrega principal.
